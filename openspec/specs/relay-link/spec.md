# relay-link Specification

## Purpose
承诺中继链路心跳新鲜度（最近一次收到心跳的时刻）在"IO 线程写入、调度线程检测"的并发下的可见性：空闲判定依据的时间戳不因发布延迟而误杀健康链路。

## Requirements

### Requirement: 心跳新鲜度对空闲检测可见
中继链路在收到并处理一次心跳后更新的心跳时刻，执行空闲检测的调度线程 MUST 能在其后续检测中观察到该更新；健康链路 MUST NOT 因心跳更新不可见而被判定空闲超时断开。

#### Scenario: 心跳刷新解除空闲判定
- **WHEN** 链路在空闲窗口内收到并处理了心跳，空闲检测在心跳处理完成后的下一个调度周期执行
- **THEN** 检测观察到新的心跳时刻，该链路不被断开

#### Scenario: 静默链路被正确判定
- **WHEN** 链路在最大空闲窗口内始终没有新心跳到达
- **THEN** 检测观察到停留在窗口起点之前的心跳时刻，链路被判定空闲并断开
