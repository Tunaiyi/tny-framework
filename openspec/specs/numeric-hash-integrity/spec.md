# numeric-hash-integrity Specification
## Purpose

数值与哈希完整性是标识生成、分桶散列、配置解析与跨端序列化的公共底座，其缺陷形态隐蔽——超长字符集静默退化成十进制假成功、窄类型参数把六十四位存储值先截断再运算、高精度数被折叠成整型、非 ASCII 输入让哈希越界或符号错叠、匿名捕获的类型令牌读错泛型层级、显示文本劫持枚举名查找、地址尾冒号被静默吞掉。本能力把这些行为面按外部可观察契约钉死：长度真实、运算原宽、分派保精度、哈希定义域与参考实现一致、类型解析取直接父层、查找以常量名为准、歧义地址显式失败，使错误方向统一收口为"正确往返或显式失败"。

## Requirements

### Requirement: 数制字符集以真实长度参与换算且不可用字符集构造期拒绝
数制字符集对外报告的长度 MUST 等于其实际容纳的字符个数，MUST NOT 被单字节宽度的域截断回绕；超过 127 个字符的字符集 MUST 以真实长度为基数参与数值按进制换算，MUST NOT 退化为"输出普通十进制文本"的假成功（**BREAKING**：超长字符集此前得到的是与声明字符集无关的十进制串，属必错路径且无正确依赖者）。含重复字符的集 MUST 在构造期显式拒绝；空集与单字符集的构造拒绝不属本规格裁定范围（维持既有宽容语义，长度如实报告——空集为 0，重复字符拒绝为唯一构造期守门）。长度在 2 到 127 的既有合法字符集，其长度报告与换算结果 MUST 与修复前逐字符一致。
#### Scenario: 常用六十二进制字符集长度真实且换算向后兼容
- **WHEN** 以数字加大写加小写字母构成的字符集报告长度，并用它对一批定种子随机数换算
- **THEN** 长度为 62，换算结果与修复前逐字符相同（既有正确路径不变）

#### Scenario: 超过一百二十七字符的字符集以真实基数换算（原假成功路径）
- **WHEN** 构造一个含 128 个互异字符的字符集，报告其长度并用它换算数值
- **THEN** 报告长度恰为 128，换算输出的每一位都取自该字符集且按 128 进制自洽（断言不等于同一数值的普通十进制文本）

#### Scenario: 含重复字符的字符集构造显式拒绝（错误路径）
- **WHEN** 以含同一字符出现两次的文本构造字符集
- **THEN** 构造当场抛出受控校验异常，不返回任何可用实例

### Requirement: 泛型数值容器的窄类型参数运算在存储值原宽进行
泛型数值容器接受窄类型参数（十六位短型、八位字节型发起的加、减、乘、除、取余）运算时，MUST 把**存储值保持满精度**参与运算、把参数值加宽对齐，MUST NOT 先把存储值截断到参数的窄宽度再运算；运算结果 MUST 按存储值自身的数值类型写回（该类型溢出域内的往返自洽）。全部参数宽度入口 MUST 与"以存储值同宽参数发起"的结果等价（**BREAKING**：此前宽存储值经窄参数入口运算得到截断垃圾值，例如六十四位容器中存放五十万量级数值后以短型参数加一，得到的是被十六位截断后的无关值而非加一后的值）。
#### Scenario: 六十四位存储值经短型参数加一得到正确后继（原截断路径）
- **WHEN** 容器持有六十四位数值 500000，通过十六位窄参数入口发起加一
- **THEN** 结果为 500001，与经六十四位参数入口加一完全相等

#### Scenario: 各宽度入口结果等价（正常路径）
- **WHEN** 同一初始存储值分别经整型、长整型、短型、字节型参数入口执行加、减、乘、除、取余（操作数选取各该类型域内值）
- **THEN** 只要数学结果落入存储类型域，各入口结果彼此一致且等于全精度算术期望值

#### Scenario: 窄存储值结果类型保型且不越界假宽（边界）
- **WHEN** 容器以短型存储 100，经短型参数入口加一再读回
- **THEN** 读回仍为短型数值 101（类型与值均按存储类型语义），运算未借助截断存储值实现

### Requirement: 高精度数参与数值工具分派不再走整型截断路径
任意精度整数与任意精度小数参与数值工具的算术与比较分派时，MUST 按其精度域选取运算路径：结果 MUST 保留完整精度，MUST NOT 被强转成 32 或 64 位整型而丢失高位或小数部分；高精度参与者的比较 MUST 与数值真值一致，MUST NOT 因窄化折叠制造伪相等或伪不等。数值向目标类型的转换入口对无法承载的陌生目标类型 MUST 显式失败，MUST NOT 静默折叠为 32 位整型交回（**BREAKING**：此前含高精度操作数的运算返回整型截断值或错误类型实例）。
#### Scenario: 超六十四位值域的任意精度加法逐位精确
- **WHEN** 两个各四十位十进制数字的任意精度整数执行算术与比较分派
- **THEN** 和与预期逐位相等（无高位丢失），二者比较结果与数值真值一致

#### Scenario: 任意精度小数保留小数部分（正常路径）
- **WHEN** 以任意精度小数 1.5 与 2.25 参与加法分派
- **THEN** 结果为任意精度语义下的 3.75，小数部分未被折叠成整数

#### Scenario: 不可承载目标的转换显式失败（原静默截断路径）
- **WHEN** 把任意精度数值经转换入口投向工具无法承载的数值类型
- **THEN** 当场显式失败（受控异常），调用方拿不到"看似成功实则截断"的错误类型实例

### Requirement: CRC 类字符串哈希以字节序列为定义域且非 ASCII 有值
CRC 类字符串哈希 MUST 以文本的字节序列（固定 UTF-8 编码，逐字节按无符号解释）为定义域：任意非 ASCII 输入 MUST 得到确定的哈希值，MUST NOT 因字符超出查表范围而抛下标越界（**BREAKING**：原本抛异常的输入域变为有值域——单向扩大，无既有正确依赖）；纯 ASCII 输入的哈希结果 MUST 与修复前完全一致；同一文本的哈希 MUST 跨调用、跨运行确定。
#### Scenario: ASCII 输入哈希值向后兼容
- **WHEN** 对一批纯英文标识串在修复前后各计算一次该哈希
- **THEN** 每个输入的新旧返回值逐一相等

#### Scenario: 多字节中文与表情符号哈希有值且确定（原越界路径）
- **WHEN** 含中文、emoji 的文本分别两次执行哈希
- **THEN** 无异常抛出，两次结果相等；不同文本的结果按哈希值区分（对给定样本互不相等）

#### Scenario: 空串与单字节边界输入正常返回（边界）
- **WHEN** 对空串、单字符串与恰含查表边界值字符的串计算哈希
- **THEN** 均返回有限整数值，空串结果与"字节序列长度为 0 的初始态折叠"定义一致且稳定

### Requirement: murmur 类哈希尾字节按无符号折叠与参考实现一致
murmur 类字符串哈希在对不足整字长度的尾字节做折叠混入时，每个尾字节 MUST 按无符号值参与（值域 0~255），MUST NOT 让高位字节（大于等于 128）的符号位经符号扩展污染高位；该尾字节折叠规则 MUST 与所引参考实现及本仓主循环、murmur2 的按无符号字节取段写法一致（**BREAKING**：尾字节含高位字节的文本哈希值改变——全仓核查活跃调用点仅使用另一族 djb 类算法，其入口不受本项影响；ASCII 输入结果不变。整体函数结果沿用本仓既有主循环与折叠常数，不要求与外部库逐位对齐）。
#### Scenario: ASCII 输入与 djb 类入口结果不变（向后兼容）
- **WHEN** 对 UTF-8 编码全为 ASCII 的文本计算 murmur 系哈希，并另经 djb 类入口计算
- **THEN** murmur 系结果与修复前逐一相等，djb 类入口行为不变

#### Scenario: 尾字节含高位字节的文本与尾字节无符号折叠参考一致（原符号扩展路径）
- **WHEN** 对长度不足整字倍数且尾部含大于等于 128 字节的多字节中文文本计算哈希，比对预先固定的"每尾字节按 0~255 无符号折叠"参考实现向量
- **THEN** 返回值与参考实现向量相等，不再出现符号折叠造成的偏差值（修复前实测偏差值必须不再出现）

#### Scenario: 尾部高位字节差异必须反映到哈希上（错误路径的消除）
- **WHEN** 两个仅在尾字节高位部分不同的同长度文本分别计算哈希
- **THEN** 两个哈希值不同——尾部字节不再因符号扩展而互相吞并

### Requirement: 类型令牌匿名捕获解析直接父层的泛型实参
以匿名子类形态捕获目标类型的引用令牌，解析其携带类型时 MUST 读取**直接父层**声明的泛型实参：MUST NOT 从实例实现的接口列表取型（此前接口列表为空或错位时直接下标越界或解析出无关类型）。解析失败的场景——原始捕获（未提供类型实参）或通配形态——转换入口 MUST 显式失败并给出受控错误，MUST NOT 抛下标越界类异常或返回错误类型的实例。经解析成功的转换执行契约：已是目标类型的实例原样通过；可转换值按目标语义转换；不可转换值显式拒绝。
#### Scenario: 捕获目标类型后转换命中正确类型
- **WHEN** 以携带字符串目标类型的匿名捕获令牌执行值转换
- **THEN** 得到字符串类型实例；已是该类型的输入原样返回同一引用

#### Scenario: 捕获实例附带无关接口仍解析正确（原越界/错层路径）
- **WHEN** 匿名捕获实例同时实现一个无关接口，再执行类型解析与转换
- **THEN** 解析结果仍是直接父层声明的目标类型，接口列表不参与取型，全程无下标越界

#### Scenario: 原始捕获与不可转换值显式失败（错误路径）
- **WHEN** 构造未提供类型实参的原始捕获令牌（其失败发生在令牌构造当场，根本到不了转换调用）；或把不可解析形态（如通配类型令牌）交转换；或把与已解析目标类型不可调和的值交转换
- **THEN** 各情形均得到受控显式失败（校验类异常），绝无下标越界、绝无静默返回错误类型实例

### Requirement: 枚举按名查找以常量声明名为索引
枚举的按名字查找 MUST 以**常量声明名**建立索引：按常量名查找恒命中对应实例；实例显示文本被自定义 MUST NOT 劫持或顶替名字查找（自定义显示文本 MUST NOT 再被当作合法名字命中——名字查找域收窄为常量名，**BREAKING**：此前显示文本恰能被用作查找键的路径失效）。多个常量显示文本彼此相同时，每个常量 MUST 仍可经各自常量名独立寻回（此前同文本互相覆盖只剩其一）。未知名字：严格入口显式失败含语境，宽松入口返回空。
#### Scenario: 未自定义显示文本的枚举按名查找向后兼容
- **WHEN** 对显示文本即常量名的普通枚举按各常量名查找
- **THEN** 全部命中对应实例，结果与修复前一致

#### Scenario: 显示文本被覆写的枚举仍按常量名命中（原劫持路径）
- **WHEN** 某枚举覆写了显示文本使其不同于常量名，分别以常量名与显示文本执行查找
- **THEN** 常量名查找命中；显示文本查找不被视为合法名字（严格入口显式失败、宽松入口空）；两个显示文本相同的常量各按其名查找均独立命中

#### Scenario: 未知名字两入口语义分明（错误路径）
- **WHEN** 以一个不存在的名字分别执行严格与宽松的按名查找
- **THEN** 严格入口抛含枚举类型与非法名字的显式失败，宽松入口返回空且不抛

### Requirement: 地址解析对尾冒号与歧义 IPv6 形态显式失败
字符串形态的服务地址解析 MUST NOT 对无法安全消歧的文本静默产出错误拼合：主机段后仅带尾冒号（冒号后端口段为空）MUST 显式受控失败（此前被当作"无端口"吞掉冒号）；含多于一个冒号的裸 IPv6 地址字面量落入门户消歧规则时 MUST 显式失败并在校验错误中指出问题文本，MUST NOT 把中间或末个冒号误切为端口分隔、MUST NOT 以裸的数字解析异常作为唯一外泄信号；地址改写与多地址拼接入口对同类歧义形态遵循同一显式失败规则。无歧义的"主机:端口"与无端口纯主机 MUST 照常解析并与修复前一致。
#### Scenario: 常规主机端口与纯主机解析向后兼容
- **WHEN** 解析 "10.0.0.1:20880" 与 "10.0.0.1" 并回输出地址文本
- **THEN** 前者主机与端口分别正确，后者端口为零/缺省语义，输出与修复前一致

#### Scenario: 尾冒号空端口显式拒绝（原静默吞路径）
- **WHEN** 解析以冒号结尾、冒号后无任何字符的地址串
- **THEN** 得到显式受控失败并含问题文本，而非"端口被丢弃、看似合法"的实例

#### Scenario: 裸 IPv6 字面量与地址改写不产生错误拼合（错误路径）
- **WHEN** 把含多段冒号的裸 IPv6 字面量交地址解析或地址改写入口
- **THEN** 显式受控失败，绝不返回"主机含部分地址段、端口取末段数值"的错切结果；失败信息为受控校验类而非裸数字解析异常
