# command-execution Specification

## Purpose
承诺命令执行环节的失败可见性：业务命令的异步失败必须以错误级日志留痕，不依赖诊断级别开关。

## Requirements

### Requirement: 命令异步失败必须留痕
会话命令执行过程中，业务命令以异步方式失败（完成异常）时，系统 MUST 以错误级日志记录该失败，日志 MUST 包含命令标识与异常原因；该记录义务 MUST NOT 因诊断级别未开启而缺失。命令成功完成时 MUST NOT 产生错误日志。

#### Scenario: 异步失败产生错误日志
- **WHEN** 某业务命令异步执行完成且携带异常
- **THEN** 错误级日志被记录，内容可定位到该命令与异常原因

#### Scenario: 成功完成无错误噪音
- **WHEN** 业务命令正常完成
- **THEN** 不产生该命令的错误级日志

#### Scenario: 后续命令不受失败影响
- **WHEN** 前序命令以异常完成后继续提交新命令
- **THEN** 新命令照常执行，执行队列不因前者失败而停摆
