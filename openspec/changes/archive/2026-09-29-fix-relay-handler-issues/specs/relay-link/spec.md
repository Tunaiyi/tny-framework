# Spec Delta

## ADDED Requirements

### Requirement: 中继通道事件传播的正确性
中继通道的激活事件 MUST 无条件向处理链下游传播（不受诊断日志开关或连接状态判断分支影响）；中继通道的写路径收到非中继包对象的写出请求时，MUST 原样向下游传递该请求（由后续环节处置），MUST NOT 静默丢弃或使写回执永久悬挂。

#### Scenario: 激活事件必然传播
- **WHEN** 中继通道完成激活，且诊断日志处于关闭级别
- **THEN** 激活事件仍传播到处理链下游，后续处理器可执行其初始化逻辑

#### Scenario: 非中继包写出不被吞
- **WHEN** 向中继通道写出一个非中继包形态的对象
- **THEN** 该写出请求传递到处理链下一环节，写回执由正常写流程完成，不出现悬挂

### Requirement: 中继包处理失败的资源终结释放
中继包在处理环节抛出任何异常（含校验拒绝型与未知型）时，该包的载荷缓冲引用 MUST 由通道处理环节终结释放，且释放恰好执行一次；处理成功路径的缓冲归属由中继处理器管理，不在此约束内。

#### Scenario: 校验拒绝型异常释放缓冲
- **WHEN** 中继包因链路状态校验不通过而被拒绝（抛出携带结果码的异常）
- **THEN** 该包的载荷缓冲被释放恰好一次，连接上无缓冲累积泄漏

#### Scenario: 未知异常释放缓冲（既有行为保持）
- **WHEN** 中继包处理抛出未预期异常
- **THEN** 载荷缓冲同样被释放恰好一次（与现状一致，纳入合同固化）

#### Scenario: 成功处理不误释放
- **WHEN** 中继包被正常受理进入转发/链接处理
- **THEN** 通道处理环节不释放该包缓冲（归属处理器）
