# Proposal

## Why

首轮 common 模块审计（`fix-common-audit-findings`，41/41 完成待归档）收口了活跃调用面上的实锤缺陷，但审查同时留下一份**休眠地雷清单**：整簇复制粘贴未闭合的命令盒/频率执行器家族、构造即不可用的锁链设施、"超时毒化共享 future"的包装 future、时钟回拨会产出重复 ID 的雪花生成器、换位重载必然哈希碰撞的反射 invoker 工厂、jar 内资源完全失效的配置加载路径、失败即永久错过且语义未声明的任务投递底座等。这些代码大多零生产调用点，一旦下游或本仓新功能启用即引爆；且首轮教训表明——**无测试的休眠簇正是缺陷温床**（`CollectionLockTest` 整文件被注释对应锁链全簇失灵）。第二轮按用户决策对遗留清单逐簇立约修复（含盲区扫荡新发现的活跃观测簇）（含改动面大的语义重设计）并补齐回归测试，把"静默失效"模式在基础设施层连根收口。

## What Changes

按行为域分组（明细与 Scenario 见各 specs 差量；全部为修复性立约，默认"立约修复"含大改）：

- **命令盒与频率执行（worker-command-boxes）**：延迟命令"未到点即执行"的判反修正（**BREAKING**）；双缓冲队列切换为恒等空操作——切换真实生效（**BREAKING**）；频率盒限步上限恒假、未完成任务回投同队列致同轮重复执行——修正遍历与回投语义；频率执行器 unregister 误写 register、心跳只调空实现致注册盒永不被处理——执行闭环；工作盒绑定命令盒时"当前线程直执行"优化恒失效修正；父盒创建子盒竞态丢子盒修正；执行器 shutdown 补全业务池关闭链、start 重入不再泄漏旧心跳、注册失败不再入列（**BREAKING**：关闭语义补全）。
- **锁设施（lock-facilities）**：批量取读锁实际拿写锁的语义修正（**BREAKING**：并发度恢复为读读并行）；锁持有器过期重建非原子致两线程同临界区修正；超时限制器判定时序修正；锁池条目随租约归还可回收的边界（哈希可变键失配防护）；锁链中断/超时路径的回滚完整性回归测试。
- **future 与执行器（futures-executor-contracts）**：包装 future 等待超时**不再毒化共享 future**（一个观察者超时不得把任务终态置异常连坐他人，**BREAKING**）；异步续接的 executor 参数被忽略修正（**BREAKING**）；手写等待原语的状态机发布可见性修正；线程池工厂同名不同参静默忽略改为显式拒绝或参数入键、提供可关闭入口（**BREAKING**）；标准线程池拒绝后不再继续入队、计数不漂移；静默吞工具不再吞中断信号（恢复中断位）。
- **并发集合契约（concurrent-collection-contracts）**：写时复制映射的读侧快照语义钉桩（获取后不再可见后续写为契约 or 活视图——立约为**获取时刻快照**，**BREAKING**）；有界固定容量映射的容量差一修正（maxSize=1 可存 1 条，**BREAKING**）；映射后备集/不可变条目基本契约测试补齐；映射构建器对引用入参静默忽略的陷阱移除（**BREAKING**：删除误用入口或改为真实装载）。
- **身份标识生成（identifier-generation）**：雪花时钟回拨处置重做——小幅回拨自旋等待下一毫秒、大幅回拨显式失败而非无限期持锁睡眠、恢复后必须重取时间且序列不回卷（**BREAKING**：异常类型与时序行为）；同毫秒多实例产号碰撞防护（实例身份参与位域或显式冲突声明）；生成器契约文档化跨进程边界。
- **加权随机抽取（weighted-random-selection）**：多轮抽取每轮恰一对象、默认项仅兜底真实落空（**BREAKING**：原返回条数不定且恒含默认值）；裸权重比较的列表抽取修正为累积权重语义（**BREAKING**：抽取分布改变——原高权重项永不可中属必错）；限次概率抽取的阈值/概率混用修正与空表显式异常；奇数长度参数越界与零权重和异常守卫；权重计数分布退化修复（权重读取恒 0 断链，**BREAKING**：休眠簇行为从"全挤一桶"变为按权重分布）。
- **反射访问器与代理完整性（proxy-accessor-integrity）**：方法查找忽略名字仅比参数——名字真实参与（**BREAKING**：原任意同参数量重载可返回错方法）；生成类缓存键纳入过滤条件/注解集（**BREAKING**：跨调用者过滤器互吞修正）；同类换位重载代理类名异或碰撞致空 invoker——类名参与顺序敏感散列；切面构建忽略值参数、失败静默返回 null——错误显式化且值生效；包装代理工厂并发首建加锁；异常包装不再把 Error 折叠成调用异常（**BREAKING**：与 cglib 实现统一为原样透传）；属性名解析产生的幽灵空键消除；泛型组件解析穿透间接实现层。
- **资源加载健壮性（resource-loading-robustness）**：classpath 资源定位对 jar 内嵌与含转义字符路径真实可用（URL 协议分派：jar/file 语义正确、不可监听场景显式告警而非静默失效，**BREAKING**：原 jar 部署热更静默不生效）；系统属性装载——空流受控异常、命名空间守卫（禁止静默覆盖 JVM 关键属性，**BREAKING**：拒绝策略）、reload 语义重定为"新增+变更"而非不可逆污染；配置构建器不再把活映射交入配置（防御复制）；并发首载单例化（监听器不双注册）；导入链去重与环检测 fail-fast；文件监听同目录多文件共享 observer。
- **生命周期扫描健壮性（lifecycle-scanning-robustness）**：单类缺注解不再终止整轮扫描（按类隔离+汇总告警，**BREAKING**：启动行为从"炸整轮"变"跳过并告警"）；注册器提供测试期清理入口（全局态可复位）；链式追加的类入口可携带优先级；阶段接口 javadoc 复制粘贴修正。
- **任务投递契约（task-delivery-contracts）**：处理器异常后水位推进语义显式化（at-most-once 入约并告警留痕）或改为可配置重试——立约为**失败仍推进但必须可观测**（**BREAKING**：静默变显式）；别名查找通道修正为可工作的查找或显式移除该公开入口（**BREAKING**）；备份保存"获取时刻快照"（**BREAKING**：原活视图跨线程序列化读到漂移内容）；处理器重名注册显式冲突；进度计算零时长边界；错过补偿有界策略（重启追赶不风暴：单周期内合并或按配置上限，**BREAKING**：宕机恢复行为改变）。
- **数值与哈希完整性（numeric-hash-integrity）**：数制字符集长度超 127 不再字节截断回退十进制；泛型数值容器对短/字节运算不再 64 位截断（**BREAKING**：原 500000L add((short)1) 得 8481）；big-decimal/big-integer 参与数字工具分派不再走整型截断路径（**BREAKING**）；CRC 字符串哈希对非 ASCII 不再越界（域修正为字节序列，**BREAKING**：原抛异常路径变为有值）；murmur 尾字节符号扩展修正（与参考实现一致，**BREAKING**：非 ASCII 输入哈希值变化——核查调用点仅 djb 在用）；引用类型解析取直接父类而非接口数组（匿名子类不再越界）；枚举按名查找不再依赖 toString 覆写；URL 解析对尾冒号/IPv6 显式失败。
- **执行观测一致性（execution-tracing-consistency）**：运行检查器的「跟踪→结束→再跟踪」同目标周期不再误报「任务没有结束」（残留判定并入完成态检查），结束路径必须真实回收登记条目（现回收误用错误键致逐目标泄漏且回收函数不可达）；跟踪起止日志的时间单位自洽（现结束侧把微秒当纳秒换算，打印时间戳偏差千倍）并显式声明时间戳基准语义（源计时非历元时刻，或改用墙钟——立约为两者单位一致且基准如实标注）；活跃消费面为模型加载/协议模式加载的耗时统计路径。
- **死抽象清理（不立约，纯移除，**BREAKING**）**：删除从未生效且签名残缺的参数签名器一族（注释体 + 两个仅被其引用的接口）、空壳类导入器——【撤销：调用面复核证实 basics/net 有 13 个活跃类型以继承方式使用，删除炸穿下游编译，维持现状并在 D1 裁决记录否决】、无任何引用的时间任务模型类与生命周期比较器死常量、零调用的函数工具与异常包装死类、恒覆盖语义的本地字符串袋、空标记接口及其误用入口、活跃类内残留的调试 main/玩笑打印三处（完成结果工厂、invoker 工厂、雪花生成器——只删残留、保留公开工厂面）。全仓 grep 零活跃引用为删除前置条件，逐条留痕；例外修正：标记接口的构建器入口在 basics 测试面有现存使用（其「静默空表」语义被既有用例依赖），删除前置为该用例迁移至普通构造，留痕注明。

首轮遗留清单三项的补齐处置：子配置视图的键集/查找作用域语义并入 `resource-loading-robustness` 立约；串行 worker 线程身份污染（完成线程 set 不 remove 的串扰面）并入 `worker-command-boxes` 线程身份契约；XML 模型加载器的反序列化全类型放行敞口属 tny-game-basics 模块（本变更范围外，另立安全变更），但其上游——调度模块对序列化库的无使用 api 依赖泄漏——纳入本变更构建卫生清理（移除未用依赖声明，非行为契约）。

**范围外**（明确不碰，避免顺手扩权）：`tny-game-boot` 侧异步生命周期处理器语义（A2 缺陷在该模块，另立变更）；`tny-game-namnspace-etcd` 测试环境债迁移（已录首轮 verification）；obsolete/ 与非活跃模块（P1 禁区）。

## Capabilities

### New Capabilities

- `worker-command-boxes`：命令盒/频率盒/延迟与循环命令/开关队列/命令执行器在提交、限步、回投、注销、关闭链上的行为契约。
- `lock-facilities`：批量锁视图（读写并行性）、锁持有器过期重建的互斥原子性、超时限制与锁池回收边界。
- `futures-executor-contracts`：CompletionStage 包装与手写等待原语在超时/中断/取消下的"单观察者不毒化共享状态"契约、线程/执行器工厂参数有效性与可关闭性。
- `concurrent-collection-contracts`：写时复制映射的快照读语义、有界映射容量精确性、映射后备集/条目基本契约。
- `identifier-generation`：雪花与序列 ID 生成器在时钟回拨、序列溢出、多实例共存下的唯一性与失败显式性契约。
- `weighted-random-selection`：加权抽取的"每轮一值、条数精确、分布按权重、兜底仅真实落空"契约。
- `proxy-accessor-integrity`：方法/属性反射访问器与代理生成在名字匹配、过滤器缓存、重载散列、异常透传、错误显式性上的契约。
- `resource-loading-robustness`：classpath/jar/文件三形态资源定位、热更监听可行性判定、系统属性装载守卫与配置构建防御契约。
- `lifecycle-scanning-robustness`：生命周期扫描注册的按类隔离、全局态可复位、追加入口优先级契约。
- `task-delivery-contracts`：定时任务投递的失败可观测性、快照一致性备份、处理器注册冲突、错过补偿有界性契约。
- `numeric-hash-integrity`：数制/数值容器/字符串哈希/泛型解析/URL 解析的边界与参考一致性契约。
- `execution-tracing-consistency`：运行跟踪观测在同目标周期重入下的误报防护、条目回收完整性、起止时间单位与基准声明的一致性契约。

### Modified Capabilities

（无——首轮 9 个能力位于未归档变更 `fix-common-audit-findings` 的差量中，主账本尚无对应条目；本轮全部以新能力立约，不与首轮产生 delta 交叠。归档顺序：先首轮、后本轮。）

## Impact

- **代码模块（被改）**：`tny-game-common-lang`（worker/command-box/lock/future/并发集合/雪花/加权/数制/哈希/event/URL/version 各休眠包——本轮主战场）、`tny-game-common-reflect`（javassist/cglib/aop 簇）、`tny-game-common-io`（资源定位与系统属性）、`tny-game-common-lifecycle`（扫描注册）、`tny-game-common-scheduler`（投递/备份/补偿语义 + 移除对 io 空壳类的继承依赖）、`tny-game-common-digest`（仅死代码删除）。
- **下游**：本轮多为零调用点休眠簇的语义修正与死代码移除，但**公共 API 删除与哈希/权重/时钟行为改变仍属发布合同变更**——BREAKING 全量入 release-note；活跃消费面中：`tny-game-basics`（`DefaultCommandExecutor` 经 `ActorCommandBox`/`ActorTheatres` 生产在用——命令盒执行器关闭链与注册失败入列修正直接受益）、`tny-game-net`（MapperLocker/HashObjectLocker 在用——锁读并行与哈希槽边界）、`tny-game-expr`/配置脚本可达面（MathAide/DateTimeAide 经 MVEL/GraalJS 暴露——权重与日期行为改变需公告策划脚本面）。
- **测试**：本轮按"每簇契约↔测试"补测，含复活被整文件注释的锁链测试（转为本轮新能力下的有效断言测试）；并发簇沿用首轮手法（栅栏+有界等待+原子计数，禁 sleep 判定）；时钟回拨用可注入时钟源改造（不改公共签名）。
- **依赖关系**：与首轮变更文件面不相交（首轮未触碰的休眠簇），两变更可并行推进，但**归档与发版顺序固定为首轮→本轮**——本轮改动面不触碰首轮已钉的字节序契约；worker 活性与 Map 单例类立约与首轮已钉契约同法同向（置等待竞态不丢唤醒、并发首写全保留），无回退风险。
- **协调**：`optimize-legacy-codec-paths`（8/10）涉及 codec 热路径，与本轮 `numeric-hash-integrity` 的哈希修正交叠面为零（其不动 djb 现用路径）；boot 侧异步生命周期语义另立后续变更。
