# Release Note（草稿，归档时并入版本公告）

fix-common-audit-findings：6 个 common 基础设施模块深度审计收口。总体性质：**十余项行为收窄/必错路径修正**——绝大多数缺陷原状态是必抛、必挂或全仓零调用，正常输入路径全部保持逐字节兼容；无报文格式变更，客户端无需升级。

## 行为变更清单（含 BREAKING 标注）

### tny-game-common-digest
- **[BREAKING] 无符号单字节解析返回域 0~255**（原 0~4095 掩码位误）：全仓零调用点。
- **[BREAKING] 对称密码 String 通道编解码统一 UTF-8**（原编码侧用平台默认字符集、解码侧用 UTF-8，非 UTF-8 平台往返可能变化）。
- **[BREAKING] RSA 分段加解密修复后多块往返成立**（原多块必抛块尺寸异常）；相关方法受检异常签名扩展（源码级兼容）。
- 数值↔字节短窗读取补齐 7 字节档位（原越界）；Base62 线程安全化（单线程结果逐字不变）。
- 加密 CBC 无 IV 构造在初始化期显式失败（现契约），ECB/固定 IV 通道行为不变。

### tny-game-common-io
- **[BREAKING] 热更读取失败保留在役配置**（原实现用空表整体清空，属 fail-open 事故源）。测试补齐（2026-10-01 修复轮）：ConfigFileListener 事件触发/失败保留双分支由 `ConfigLibHotReloadTest` 钉桩（此前 tasks 2.1 误归因已更正）。
- **[BREAKING] 导入来源不可读时装载显式失败**（2026-10-01 修复轮新增）：首载路径（构造/用户触发 reload）抛含装载链的受控异常，整次装载以失败结束；热更路径收容 reload 异常、保留在役配置并 error 告警。原缺陷面：null 属性流被换成空表静默合并——"成功但缺内容"的假成功。
- **[BREAKING] 词表首载失败上抛、热更读失败保留旧词表**（原实现空词表带病启动——聊天审核整体失效）。
- **[BREAKING] 子配置七个单参取值方法由常量桩改为委托父配置**（原恒 0/false/null）。
- 嵌套子配置前缀只剥一次；null 配置值抛含键名异常；reload 通知逐监听器隔离；import 列表逐项 trim；监听注销改真移除；输入流基类统一关闭；配置表/词表引用 volatile 化。

### tny-game-common-lang
- **[BREAKING] 属性键按全名原子创建**：同 (命名空间,名) 恒等实例、跨命名空间互不可见（原查询用短名致命名空间劫持与双实例；net/starter 混用两种键风格的调用点核查后行为只变得更正确）。
- **[BREAKING] 窗口写入只计实际字节数**（原按整个源数组长度计数，污染 protoex 序列化长度前缀）。
- **[BREAKING] 排队期间已超时的任务不再执行副作用**（原超时后照常执行、结果丢弃）。
- **[BREAKING] 三族惰性空表并发首写原子化**（原各建各表互相覆盖丢数据——事件通知器/etcd 监听为生产路径）。
- **[BREAKING] toMap 重复键 last-win**（原抛 IllegalStateException）；**空迭代器 next() 抛 NoSuchElementException**（原返回 null）；**完成结果 map 方向修正**（原条件写反：失败结果进映射、成功结果抛异常）。
- **[BREAKING] Map 访问器包装实现与非包装实现转换语义统一**（热点直取 + 错型宽松转换：数字串→数值、数值窄化、toString）；size() 反映真实条目（原恒 0）；浮点缺省通道修复（原必抛）。
- **[BREAKING] 全局监听器移除真实移除**（原误写为追加）；锁槽哈希改用 floorMod（原 Integer.MIN_VALUE 越界）；锁链构造条件写反修正 + 失败回滚（原完全不可用）；关单资源比较器赋值笔误修正；ifNotBlank 两重载语义同向（原 String 版反转）；数字比较消 int 相减溢出；数字位数对齐表溢出/上界 NPE/负位数三守卫；版本号分段截取差一修正；布尔工具静态化。
- 串行/单线程 worker 环活性：超时钩子唤醒 + 置等待前竞态补偿 + 迟到完成归属校验（嵌套 await 编排形态保持不死锁，既有测试钉桩）。
- 链式缓冲：扩容复利、三参追加等价、release 复位尺寸。

### tny-game-common-lifecycle
- **[BREAKING] 优先级双边越界显式拒绝**（原整数溢出产出"假最高级/0 级"）。
- **[BREAKING] 静态初始化多方法全部执行且方法名定序**（原仅随机执行其一）；初始化业务异常原类型上抛（反射包装解包）。
- **[BREAKING] 阶段注册表并发首注册单例**（原丢注册/抛"已经存在"/双实例）；单元注册"全有或全无"（原半注册残留且重试必炸）。

### tny-game-common-reflect
- **[BREAKING] getter 形态判定修正**（原误用 setter 判定，语义颠倒；并收紧为"无参且非 void"；全仓调用点核查为休眠 API）。

### tny-game-common-scheduler
- **[BREAKING] 同执行时间任务处理器合并**（原整批静默丢失）；**恢复保留最新 N 条**（原保留最旧丢最新）；**maxSize≤0 入队不再死循环**（原调度线程永久挂死）。
- **[BREAKING] 触发器比较器全序化**（原相等返回 -1 违反 Comparable 契约，跳表 first/pollFirst 顺序未定义致任务迟到/翻倍）。
- **[BREAKING] 挂起/恢复/延长时间全程完整 long**（原 int 截断致超 24.86 天时间回退）；lengthen 成功返回 true（原恒 false）；停止清理挂起态；restart 空起点不再 NPE/覆盖；无未来触发点 cron 受控失败且单方案失败不连坐全表；互斥锁写锁笔误修正（原"写"路径全部共享读锁互不排斥）；执行池实例化（原多调度器共享静态池互杀）；shutdown 置终态并取消待执行任务。

## 兼容性核查结论
- 全部小端序列化、Base62 字母表、URL-safe 密码输出、cron/duration 周期计算格式不变——已发出的正确报文/已存储的备份在新版本可正常解析（调度备份的"恢复方向"仅影响超限截断取舍，见上）。
- `MapAccessors.wrap` 活跃调用 2 处（接入节点/中继实例信息，值即目标类型路径）行为不变。
- 已知 IDE「not exported」告警为工程模型失同步（mavenLocal 快照 jar 与源码模块重名），代码侧无缺陷：涉事接口本为 public、无 module-info、javac 全量编译通过；处理方式为 Gradle re-sync，不引入 module-info（P10 无第二消费者证据）。
