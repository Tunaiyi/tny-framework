# Spec Delta

## ADDED Requirements

### Requirement: 构建工具基线升级与工具链告警归属成册
构建工具（Gradle 发行版本身）的版本变更 MUST 由一个变更册承载，册内 MUST 写明该版本下全量构建在新式告警输出模式下的工具链兼容告警清单及其处置（修复清零或书面移交归属）；移交归属的条目 MUST 指名承接的在途册或另立册，MUST NOT 以默认输出不显示为由静默积累。发布产物（Maven POM 与 Gradle 模块元数据）在基线升级前后 MUST 保持依赖条目零漂移，除非升级册本身明文申报了差异。

#### Scenario: 基线升级册携零告警与零漂移收口
- **WHEN** 一次承载构建工具版本升级的变更进入收口，以新式全量告警模式执行构建并核对发布元数据基线
- **THEN** 告警清单内每条要么计数归零、要么持有指名承接册的移交记录；发布 POM 与模块元数据对升级前基线逐条目零漂移，两者齐备该册才可归档

#### Scenario: 告警无归属时升级册不得收口
- **WHEN** 构建工具版本升级后仍存在既未修复清零、也未登记移交归属的工具链兼容告警，实施者试图收口
- **THEN** 核验判定不通过：告警要么在任务清单中有对应处置项，要么在移交记录中指名了承接册；"警告默认不显示"不构成豁免理由
