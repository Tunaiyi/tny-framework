# Proposal

## Why

对网络层 8 个模块（tny-game-net、tny-game-net-netty4、两个 codec 模块、starter 两个模块及 demo/test）约 720 个源文件完成了全量深度审计，确认了一批可单行复现的实锤缺陷：两处 P0（未认证远程可触发编解码 OOM；链路切换包类型错标导致故障转移销毁业务会话）、两处 ABBA 死锁（会话换绑×隧道断开、集群摘除×链路注册，event-loop 或中继调度线程可被永久锁死）、协议级 ID 生成与十进制拼位的越界/撞号缺陷、鉴权与派发链多处"注册即崩/静默不生效"、停机主路径死分支、以及 header/attributes/pending-future 等一批跨线程数据竞争。这些问题集中表现为三个横切模式：**失败路径不闭环、协议自报无防线、生命周期只装了一半**，若不系统性收口，任何单点修补都会被同族缺陷再次击穿。

## What Changes

按问题域分组修复全部已确认的 P0/P1/P2 发现（P3 仅随同文件顺带处理，不单独立约；与 `fix-relay-registry-leak` 重叠的中继注册表摘除项**不在本变更范围**，由该变更承接）：

- **报文编解码防线（P0）**：帧内 varint 声明长度必须先校验 `0 ≤ length ≤ readableBytes` 再分配；解码异常路径缓冲终结释放；编码失败**零字节上线且本次写回执失败**（杜绝半截帧+假成功）；header 声明计数与实际编码计数不一致即整帧失败；加密/校验启用时缺失密钥配置启动期 fail-fast（杜绝首包除零）；心跳报文处理不得触碰跨连接共享可变状态。
- **报文标识唯一性**：消息 ID 生成器分片位宽修正（消除跨分片撞号）；接入身份十进制拼位增加下界与回代校验（杜绝借位漂移）。
- **中继协议语义修正**：链路切换包必须按"隧道迁移"语义处理，不得销毁重建会话（**BREAKING：需网关/业务服成对升级，旧新混跑期的兼容策略见 design**）；切换失败回执使用正确包类型；链路分配策略下标不得为负；链路关闭/异常早退路径中继缓冲立即终结释放、消息丢弃必须可见；链路未识别时协议错误处理不得被观测日志的 NPE 顶替。
- **会话层正确性**：凭证新旧比较修正（当前恒失效致顶号防线形同虚设）；顶号顺序改为"新会话接管成功后才关闭旧会话"；下线事件幂等单次派发（消除递归溢出与重复入队）；会话属性容器并发读写不丢数据、不损坏结构；会话清理任务可停止、异常不自杀、不产生孤儿注册。
- **请求-响应闭环**：会话关闭与发送竞态下每个请求 future 必须至多且必然完成（含提交被拒路径）；接收过滤拒收响应时必须完成或取消已登记的请求 future；多目标广播不得共享同一请求内容/响应 future。
- **命令派发与检查链**：全局/协议级鉴权校验器可注册且实际生效（当前注册即 NPE、注册后死路）；作用域过滤复制粘贴修正；建立"每个请求必须且只收到一个终答"的完成协议（处理异常、中继转发失败、超时拦截路径全部回错误码，不再静默悬挂）；异步命令具备超时兜底，单条挂死不得饿死同会话后续命令；PONG/未知模式命令派发不再 NPE 刷屏；检查插件对空可选参数缺省值配置正确放行（不再拆箱 NPE 误拒合法流量）；参数校验注解与过滤器注册的覆盖关系启动期校验（未注册的注解 fail-fast 告警，杜绝静默不执行）。
- **通道并发与事件**：消除隧道锁与会话锁 ABBA 死锁；通道事件按"激活→失活→关闭"全序单次派发；连接超时配置真实生效；断线重连调度不因竞态或失败路径永久熄火。
- **引导器生命周期**：停机主路径死分支修正——关闭必须真实执行监听释放、通道摘除与停止事件发布（**BREAKING 范围：仅行为修正，不改公开签名**）；关闭后重开恢复完整能力（缓存的引导器随组一并重建）；绑定失败对启动路径可感知且不得把未监听的服务器注册进服务发现。
- **RPC 注册表（新能力 `net-rpc-registry` 立约）**：节点有序快照的发布原子化（消除 last-writer-wins 丢失活跃节点）；节点摘除后注册表按活性收缩、移除路径不得复活空节点；节点激活/失活回调条件修正（当前恒反向/不可达）；接入节点集合绑定的不安全发布与静默忽略修正；指定接入未命中时的随机回退必须留痕；转发者字段装配的自引用复制粘贴修正。
- **中继集群视图（新能力 `relay-cluster-view` 立约）**：消除实例锁与链路锁 ABBA；实例注册的发布纳入锁域；节点健康翻转对分配视图真实生效；集群命名键空间统一；链路心跳调度随视图终结可取消、异常不自杀；重复注册幂等且失败路径不留下已启动的孤儿连接器。
- **Spring/APM 集成（新能力 `net-boot-integration` 立约）**：服务注册与注销对称（注册后必须入列表，重启不堆积幽灵实例）；服务节点订阅的注册表随实例生命周期、重订阅可复活、订阅失败不得被吞；自动配置对可选运行时依赖声明类条件（无 APM agent 环境可启动）；RPC 代理注册不再在容器刷新前强制实例化依赖图；引导器 bean 不再双路同名注册（默认配置可启动，不再依赖 bean 覆盖兜底）；发现开关语义自洽（显式关闭必须生效）；APM 监视处理器跨线程 span 必须闭合、快照属性随异步完成清理、挂起不得连坐无关 span。
- **死抽象清理**：删除从未生效且语义反转的连接回调五件套与无人消费的连接模式开关、永不触发的通道接收事件契约、无实现的全局上下文注册器（**BREAKING：移除 tny-game-net 公共类型**，全仓检索确认零引用）。

## Capabilities

### New Capabilities

- `net-rpc-registry`：RPC 服务节点注册表在"任意 IO 线程并发增删 × 任意业务线程并发路由"下的发布原子性、节点生命周期收缩、激活事件单发性与回退可见性契约。
- `relay-cluster-view`：网关侧中继集群视图（实例集合/健康/活跃链路快照）在 nacos 回调线程与 relay 调度线程并发下的一致性、锁序与调度生命周期契约。
- `net-boot-integration`：网络层 Spring Boot 装配与服务发现/APM 集成的行为契约——注册注销对称、订阅生命周期完整、条件装配在无可选依赖环境可用、装配阶段不产生半初始化单例、停机事件真实发布。

### Modified Capabilities

- `net-protocol`：新增"帧内长度声明有界校验与分配前拦截"“编码失败零字节上线且回执失败”“加密/校验配置启动期完备性”“报文标识唯一性与拼位边界”四条 Requirement；各含向后兼容 Scenario。
- `relay-link`：新增"链路切换按迁移语义处理且不销毁会话”“中继缓冲在早退路径终结释放”“链路未识别时协议错误处置不被观测代码顶替”三条 Requirement（切换包类型修正含新旧版本兼容 Scenario）。
- `net-session`：新增"凭证新旧比较自洽”“顶号接管成功后才终结旧会话”“下线事件单次且幂等”“会话属性容器并发安全”“会话清理任务可终结且异常不自杀”五条 Requirement。
- `net-tunnel`：新增“断开与换绑并发不互锁（锁序契约的可观察面）”“通道事件全序单派发”“连接超时真实生效与重连调度不熄火”“写提交失败必须完成回执”四条 Requirement。
- `command-execution`：新增“鉴权校验器注册可用且按协议维度生效”“每个请求恰好收到一个终答”“异步命令超时兜底不饿死会话队列”“未知模式命令安全吸收”“作用域过滤真实生效”五条 Requirement。
- `message-checking`：新增“检查器对空可选值与缺省配置的正确放行”“注解与过滤器覆盖关系启动期校验”两条 Requirement（保持既有"插件异常 fail-closed"语义不变）。
- `net-guide-lifecycle`：新增“停机路径真实执行关闭并发布停止事件”“启动失败对发起方可感知”两条 Requirement（关闭后重开、监听状态真实性等既有契约由本变更以修复实现兑现，不重复立约）。

## Impact

- **代码模块**：`tny-game-net`（application/session/transport/message/command/rpc/clusters/relay/codec 各包，主体）、`tny-game-net-netty4`（network/codec/relay/channel）、`tny-game-common-lang`（`AbstractAttributes` 属性底座）、`tny-game-starter-net-netty4`（nacos/rpc/relay/filter/configuration）、`tny-game-starter-net-apm-skywalking`。
- **下游 starter/业务**：依赖 `com.tny.game:tny-game-net*` 的下游工程受三类影响——①死抽象删除（BREAKING，需发版说明）；②链路切换包类型修正要求网关与业务服**成对升级**（混跑窗口策略见 design）；③消息 ID 分布改变（格式不变，向后兼容）。
- **对应实现/测试模块**：`tny-game-net-netty4-codec-jprotobuf`（并发回归压测用例）、`tny-game-net-test`/`tny-game-net-demo`（装配示例需随 bean 双注册修正回归；demo 的 `allow-bean-definition-overriding: true` 兜底应移除）。
- **进行中变更协调**：`fix-relay-registry-leak`（linkMap/tunnelMap 摘除）保持独立推进，本变更的 tasks 不含该组，规格不重复立约；两者的回归测试在同一批 relay 用例上叠加验证。
- **测试债**：按 config 约定，每条 Requirement 的 Scenario 对应补 JUnit 5 测试（核心链路 dispatcher/attributes/certificate 等当前零覆盖）。
