# Spec Delta: net-boot-integration

## Purpose
定义网络层 Spring Boot 装配与服务发现、APM 集成的行为契约：注册与注销的对称性、订阅组件的生命周期完整性、可选运行时的条件装配、容器装配阶段不产生半初始化共享单例、bean 定义唯一性与配置开关语义。

## ADDED Requirements

### Requirement: 服务注册与注销对称
向服务发现注册的每个服务实例 MUST 被登记并可逐一注销；应用停止后注册中心 MUST NOT 残留本进程的实例；地址变更触发的重启 MUST 先注销旧实例再注册新实例，注册中心 MUST NOT 堆积幽灵实例。
#### Scenario: 正常启停对称
- **WHEN** 应用启动注册若干实例后关闭
- **THEN** 注册中心中本进程实例全部消失，注销次数与注册次数一致

#### Scenario: 变更重启不堆积
- **WHEN** 地址变更触发注册重启
- **THEN** 旧实例先被摘除，注册中心仅保留一个有效实例

#### Scenario: 注册失败可重试
- **WHEN** 注册过程中途抛异常
- **THEN** 组件状态允许后续重试，不卡在"已启动但未注册"的冻结态

### Requirement: 服务节点订阅生命周期完整
服务节点订阅组件 MUST 将底层订阅失败显式上抛以使重试策略生效，MUST NOT 静默吞掉；订阅登记 MUST 随所属实例终结而清理；已终结实例被重新订阅时 MUST 可复活而非永久静默失效。

#### Scenario: 订阅失败进入重试
- **WHEN** 底层订阅抛出异常
- **THEN** 失败向上传播，按重试策略重新订阅，期间状态可观察

#### Scenario: 终结后可复活
- **WHEN** 同一进程内第二个应用上下文对同名服务重新订阅
- **THEN** 新订阅生效并收到变更通知

#### Scenario: 终结清理彻底
- **WHEN** 订阅实例关闭
- **THEN** 其登记条目随实例消失，不再钉住旧实例引用

### Requirement: 可选运行时的条件装配
依赖可选运行时（如链路追踪 agent）的集成 MUST NOT 使缺失该运行时的环境启动失败：类加载不可用时 MUST 自动禁用集成并输出说明日志；显式禁用开关 MUST 生效。

#### Scenario: 运行时缺失仍可启动
- **WHEN** 引入集成模块但未安装对应运行时
- **THEN** 应用正常启动，集成自动关闭且有说明日志

#### Scenario: 运行时存在则启用
- **WHEN** 运行时就绪且开关未禁用
- **THEN** 集成生效，采集正常工作

#### Scenario: 显式禁用优先
- **WHEN** 配置显式禁用集成
- **THEN** 无论运行时是否存在，集成均关闭

### Requirement: 装配期不产生半初始化共享单例
网络相关 bean 的注册 MUST NOT 在容器刷新完成前强制实例化共享单例；被装配图引用的集合依赖（如同类型的多个策略实例）MUST 在启动完成时完备，MUST NOT 因注册先后顺序静默缺员；单例的初始化回调 MUST 正常执行。

#### Scenario: 代理延迟生效
- **WHEN** 远程服务代理在配置解析阶段被声明
- **THEN** 其实例化发生在首次使用或容器就绪后，依赖图完整初始化

#### Scenario: 集合依赖完备
- **WHEN** 多个同类策略 bean 在不同配置类中声明
- **THEN** 启动完成后消费者可见全部策略，无顺序性遗漏

### Requirement: bean 定义唯一与开关语义有效
默认配置（未放宽 bean 覆盖）下 MUST 可启动：不同装配路径 MUST NOT 产生同名或同类型的重复定义；功能开关显式关闭时 MUST 生效——声明了静态节点列表且显式关闭服务发现时，系统 MUST NOT 发起任何订阅。

#### Scenario: 默认配置可启动
- **WHEN** 标准发现配置在关闭 bean 覆盖的环境启动
- **THEN** 无冲突异常，端口监听正常

#### Scenario: 开关显式关闭即生效
- **WHEN** 服务发现被显式禁用且提供静态节点列表
- **THEN** 仅静态列表生效，不创建订阅

#### Scenario: 用户覆盖语义明确
- **WHEN** 用户自定义同类型 bean 覆盖默认实现
- **THEN** 覆盖按预期生效，不出现两份并存实例
