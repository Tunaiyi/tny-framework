# Spec Delta

## ADDED Requirements

### Requirement: 全体广播覆盖全部注册会话且离线消息入窗
面向全体会话的广播投递 MUST 覆盖大管家当前注册的全部会话，包括处于断线保留态（离线）的会话——这是断线恢复链路的有意组成，不得按"在线过滤"修复：对在线会话直接投递；对离线会话，广播消息 MUST 仍按其配置进入该会话的已发送重发窗口（供恢复后经重发操作补收），且单个离线会话的处理 MUST NOT 向调用方抛出异常或中断对其余会话的广播。

#### Scenario: 在线会话即时收到广播
- **WHEN** 全体广播发出且目标会话在线
- **THEN** 该会话收到广播并进入其发送记录

#### Scenario: 离线会话广播入重发窗口
- **WHEN** 全体广播发出且目标会话处于离线保留态
- **THEN** 广播不即时送达（通道已断，属预期），但该消息存在于其重发窗口可被后续重发操作选取

#### Scenario: 恢复后可补收历史广播
- **WHEN** 离线会话完成重连恢复，业务对其执行按窗口的重发
- **THEN** 断线期间的历史广播随重发补送给该会话（有意的消息必达语义）

#### Scenario: 混合在线状态广播不中断
- **WHEN** 注册表中同时存在在线与离线会话并触发全体广播
- **THEN** 全部会话均完成各自处置（在线送达/离线入窗），广播调用正常返回无异常
