# Spec Delta

## ADDED Requirements

### Requirement: 通道层未绑定会话的可诊断拒绝
通道对象已建立但其会话尚未绑定时收到消息，通道层 MUST 以可诊断的告警拒绝该消息（含通道标识与消息标识），MUST NOT 以空指针等未受控异常形态失败；拒绝后通道自身状态不受影响。本条与"会话未就绪丢弃"（处理链层）分层互补：前者覆盖消息已进入通道接收入口但会话引用缺失的场景。

#### Scenario: 未绑定即拒绝且留痕
- **WHEN** 直接以未绑定会话的通道调用其消息接收入口并投递一条消息
- **THEN** 接收返回"未受理"，告警日志可定位该通道与消息，无空指针异常抛出

#### Scenario: 拒绝不损伤通道
- **WHEN** 上述拒绝发生后，会话完成绑定，再投递消息
- **THEN** 消息按正常流程受理，通道功能不受先前拒绝影响
