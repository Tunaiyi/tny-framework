# Spec Delta

## ADDED Requirements

### Requirement: 发布线构件的依赖坐标为发布级形态
执行发布任务前，构建系统 MUST 校验发布线全部构件声明的直接编译与运行依赖坐标：任一坐标携带快照、候选发布或里程碑等预发布后缀且未列入豁免登记时，发布 MUST 被拒绝，错误信息逐项列出违规坐标与声明它的构件。确因上游供给限制需要保留预发布依赖的构件，MUST 以版本库内的豁免登记清单成文记录，每一条豁免登记 MUST 同时写明保留理由与处置去向（由哪个后续变更转正）；豁免清单之外的预发布形态坐标一律按拒绝处理，发布门禁的执行输出 MUST 展示当前生效的豁免登记条目。

#### Scenario: 依赖全为发布级形态时门禁通过
- **WHEN** 发布线全部构件的直接依赖坐标均为正式发布形态，豁免登记清单为空或仅含与本册构件无关的条目
- **THEN** 门禁该项检查通过，发布继续执行，输出确认无预发布依赖

#### Scenario: 未豁免的快照依赖拒绝发布
- **WHEN** 某发布构件的直接依赖坐标为 `1.0.0-SNAPSHOT` 且未出现在豁免登记清单中，发布者执行发布任务
- **THEN** 发布被拒绝，错误信息列出该坐标与声明它的构件名，并提示豁免须经登记清单成文而非绕过门禁

#### Scenario: 已豁免条目放行且可见
- **WHEN** 某构件依赖 `2.5.0-rc1` 形态的预发布坐标，且豁免登记清单中存在覆盖该坐标、写明保留理由与处置去向的条目，发布者执行发布任务
- **THEN** 发布被允许执行，门禁输出展示该豁免条目（坐标、理由、处置去向），使例外对每次发布可见可审计
