# Spec Delta

## Purpose

定义会话对"已发送消息"的缓存与重发行为：缓存可在会话生命周期内动态启用/禁用，以环形窗口保留最近消息供重发，重发操作只作用于窗口内消息，且在会话关闭后安全无效。

## ADDED Requirements

### Requirement: 发送缓存的动态启用与禁用
会话 MUST 支持在生命周期内调整已发送消息缓存大小：从未启用调整为正数 N 后开始保留消息；调整为 0 MUST 停止保留并释放已保留的消息；任何调整 MUST NOT 抛出异常或以其它方式破坏会话可用性。

#### Scenario: 禁用状态下首次启用
- **WHEN** 会话以缓存禁用状态创建，随后缓存大小被调整为正数 N
- **THEN** 调整正常完成，会话此后的发送开始被保留（上限 N 条），会话收发功能不受影响

#### Scenario: 运行中禁用缓存
- **WHEN** 缓存已启用且保留了若干消息，缓存大小被调整为 0
- **THEN** 保留停止，已保留消息被释放，后续发送不再保留，调整不抛异常

#### Scenario: 容量调整保留最近消息
- **WHEN** 缓存从容量 M 调整为容量 N（均已启用）
- **THEN** 调整不抛异常，保留的消息不超过新容量 N 且为最近发送的部分

### Requirement: 环形保留窗口与重发范围
缓存启用时，会话 MUST 以"最近 N 条"为上限环形保留已发送消息，更早的消息被挤出 MUST NOT 造成内存无界增长；重发操作 MUST 仅重发窗口内满足调用方条件（谓词或编号区间）的消息，且重发 MUST NOT 重复保留或破坏窗口内容。

#### Scenario: 超出容量的挤出
- **WHEN** 缓存容量为 N 且会话连续发送 N+k 条消息
- **THEN** 仅最近 N 条可被查询与重发，最早的 k 条已不可见

#### Scenario: 按条件重发窗口内消息
- **WHEN** 调用方以编号区间发起重发且区间部分落在窗口外
- **THEN** 仅窗口内且属于该区间的消息被重发，窗口内容保持不变

### Requirement: 会话关闭后的重发安全
会话进入关闭状态后，任何重发请求 MUST 安全无效：不抛出异常、不产生任何对外发送、不改变会话终态。

#### Scenario: 关闭后重发
- **WHEN** 会话已关闭，调用方发起任意形式的重发
- **THEN** 调用立即返回，无消息发出，无异常抛出

#### Scenario: 关闭后查询缓存
- **WHEN** 会话已关闭，调用方查询已发送消息
- **THEN** 返回空集合或既有内容的安全快照，不抛出异常
