# enumeration-facade-semantics Specification (Delta)

## Purpose

为枚举注册门面的查找与位宽解析钉死统一语义：严格通道不得静默降级、空标识符显式失败、道具位号解析按单一商式收敛。翻转去重轮钉桩的三处门面缺陷。

## ADDED Requirements

### Requirement: 严格校验通道不得降级为宽松空返
注册门面的校验入口（字符串与数字标识两形态）MUST 与兄弟门面同持严格语义：未注册身份 MUST 以携带身份信息的显式失败拒绝，MUST NOT 返回空值放行（**BREAKING**：此前一族门面的校验通道委托了宽松查找，未命中静默返回空）。

#### Scenario: 未注册身份校验显式失败（错误路径）
- **WHEN** 以未注册的名称或数字标识调用校验入口
- **THEN** 当场显式失败且信息可定位该身份；调用方不会拿到空引用继续执行

#### Scenario: 已注册身份校验照常通过（正常路径）
- **WHEN** 以已注册身份调用校验入口
- **THEN** 返回该枚举实例，行为与差量前一致

### Requirement: 空标识符查找显式失败不越界
按别名/文本标识查找的入口对空串与纯分隔符输入 MUST 以受控失败拒绝（信息指明非法输入），MUST NOT 因内部拆分剥段产生下标越界类非受控异常。

#### Scenario: 空串别名查找受控拒绝（错误路径）
- **WHEN** 以空字符串调用别名查找
- **THEN** 受控异常拒绝且信息含输入描述，无越界类堆栈外泄

#### Scenario: 合法别名查找不受影响（正常路径）
- **WHEN** 以已注册别名调用查找
- **THEN** 返回对应实例，行为与差量前一致

### Requirement: 道具位号解析按模型段商式单一规则收敛
以全局唯一号解析所属模型号时，MUST 使用单一规则：对全局号反复以十进制取商剥位至首位数字，以首位数字乘段基址还原模型号（等价于"取首位、归段基址"；措辞按 design D5 号段证据裁定同步——原字面"对段大小取商"对超段宽样本自相矛盾），同一模型下全部序列号 MUST 解析到该模型条目（**BREAKING**：此前分位阶梯先行缩位、再叠段内截断，任意输入实际恒解析到段基址 0 号位，道具类型解析链路长期以恒失败/零号命中运行）。

#### Scenario: 同模型序列号全部归位其模型
- **WHEN** 对模型号 2000000 下不同位宽的序列号（如 2000001、2500000999）执行解析
- **THEN** 均解析回 2000000 对应条目；未注册模型段则按既有宽松/严格入口各自语义返回

#### Scenario: 消费面哨兵以真实号段验证（回归路径）
- **WHEN** 以道具类型注册表的真实模型号段构造解析输入
- **THEN** 命中结果与"该序列号所属模型"一致；既有校验/枚举通道的其他需求行为不变
