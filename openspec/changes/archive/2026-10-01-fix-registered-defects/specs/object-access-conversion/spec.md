# object-access-conversion Specification (Delta)

## Purpose

增补两实现转换失败消息的一致化契约。既有需求（类型命中直取、浮点取值正常返回、宽松转换统一）不变；本差量收敛其残留的消息面分叉。

## ADDED Requirements

### Requirement: 类型转换失败消息对两实现恒以装箱形态描述目标类型
包装键值视图与底层映射视图的带缺省值转换入口在遇到不可转换存储值时，失败消息 MUST 以同一形态描述目标类型（装箱类名或其一致简名，二者取一后全路径统一），两实现对同输入 MUST 产出逐字相同的消息尾段（**BREAKING**：此前同一语义缺陷参数在两侧产出 `float` 与 `java.lang.Float` 两种尾段；随参数一并归一为装箱形态）。

#### Scenario: 同输入两实现消息逐字一致（正常路径）
- **WHEN** 对浮点读取入口的两侧实现喂入同一无法转换的存储值与同一缺省路径
- **THEN** 两实现的失败消息（含目标类型描述尾段）逐字相等

#### Scenario: 可转换路径行为不变（回归路径）
- **WHEN** 存储值类型正确或可宽松转换
- **THEN** 读取正常返回值，不进入消息路径；既有"类型命中直取、浮点正常返回"契约逐格保持
