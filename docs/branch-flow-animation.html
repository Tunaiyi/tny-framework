分支模型流程动画（开发版本分支加常驻维护分支模型）

特性在开发版本分支 dev/N.M.x 生长，首发经集成到主干进入 main 并删除该线；
每个已发布系列由常驻 release/N.M.x 维护分支滚动补丁，补丁经向上合并逐级回到更新的分支与 main；
release 标签一经推送永不移动，是版本号、制品与提交三者对账的权威依据。依据 docs/release-process.md 与规格 release-versioning、branch-integration-gates 绘制。

main 集成主干 开发版本分支 release 维护分支 集成或向上合并节点 ⚑ release 标签 feat 分支、fix 分支 祖父登记线（过渡） ▶ 集成到主干 ╌ 向上合并与同步 ╌ 切出 ⛔ 禁止与检查

十二步：分支种类与铁律、开发版本分支与 feat 分支、同步与集成到主干、首发与常驻维护分支、补丁滚动、向上合并与完整性检查、并行排队、例外通道、祖父轨、退役与总账。键盘左右方向键翻页；命令中远端名一律 github。
