分支模型总览（redesign-devline-integration-model 目标模型）

四条泳道自上而下：并行的开发版本分支、main（集成主干）、release 维护分支（含其 release 标签）、祖父登记线。
依据 docs/release-process.md 与 openspec 规格 release-versioning、branch-integration-gates 绘制。

开发版本分支（dev/） main 集成主干 release 维护分支 集成合并节点 ⚑ release 标签（附注，永不移动） 祖父登记线 ▶ rebase-merge 合入 ╌ 同步与向上合并 ⛔ 禁止与前置检查
