项目介绍

TnyFramework 是一个企业级的游戏服务器框架，采用现代化的技术栈和模块化设计，为开发者提供从网络通信、数据存储、业务逻辑到分布式服务的完整解决方案。框架按功能层拆分为 55 个活跃模块，业务工程可以通过 Maven BOM 对齐版本，并只引入自己需要的 Spring Boot Starter。

高性能网络通信基于 Netty 4 的异步 IO，封包内置加密、校验与废字节防嗅探机制。
模块化设计55 个活跃模块按功能分层组织，按需集成，互不牵连。
多实现可插拔编解码、脚本引擎、数据存储都提供多种实现供选择。
分布式架构内置基于 Etcd 的服务发现、一致性哈希分片与 RPC 调用支持。
可观测性集成 Apache SkyWalking APM，支持分布式追踪与性能分析。
Spring Boot 集成八个开箱即用的 Starter，覆盖网络、编解码、数据与运维能力。

快速开始

构建需要 JDK 21 与 Gradle 7.0 以上版本；MongoDB、Redis、Etcd 均为可选依赖。业务工程引入方式如下：

dependencies {
    implementation platform('com.tnydev.game:tny-game-bom:<版本>')
    implementation 'com.tnydev.game:tny-game-starter-net-netty4'
    implementation 'com.tnydev.game:tny-game-starter-codec'
    implementation 'com.tnydev.game:tny-game-starter-data'
}

配置示例与完整使用教程请查阅仓库 README。

质量与基准

框架采用两级验证通道：单元测试不依赖 Docker，可随时运行；集成测试分为无容器档（真实 TCP 网络链路）与容器档（Testcontainers 数据访问与 Starter 装配剧本），后者随 CI 的 PR 通道一并执行。每次框架代码合入受监控分支时，CI 会以速览规模运行 JMH 基准，夜间定时运行完整规模；全部结果汇入基准性能趋势页，历史曲线用于辅助人工判断性能回归。
